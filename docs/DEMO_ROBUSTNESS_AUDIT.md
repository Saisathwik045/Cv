# Synthetic dashboard robustness audit

No patient data, checkpoint loading or real-model inference is needed for this
audit. Tests exercise the existing frozen decoder/preparation and session code
using generated bytes, an uninitialized service for preparation, and mocked UI
backends. No scientific or frozen inference implementation was changed.

| Boundary | Existing/new evidence | Result |
|---|---|---|
| Empty, invalid and >20 MiB input | Existing `test_demo.py` decoder test | Covered |
| Missing eye blocks prediction | Existing `test_demo.py` / `test_submission_demo.py` | Covered; a single eye is never duplicated |
| Truncated PNG/JPEG with initially valid headers | New `test_demo_robustness.py` | PASS; decode rejects |
| Unsupported BMP content | New robustness test | PASS; JPEG/PNG contract retained |
| Declared >25 million pixels | New PNG IHDR/CRC fixture; no large bitmap allocation | PASS; rejected before payload decoding |
| Grayscale and RGBA | New generated fixtures | PASS; decode normalizes to RGB |
| EXIF rotation | New JPEG orientation fixture | PASS; dimensions are transposed correctly |
| Extreme 1×16384 / 16384×1 pairs | New generated fixtures, no model object | PASS; finite `(2,3,224,224)` tensors and two canvases |
| Twenty replacement/removal/reset cycles | New state fixture | PASS; stale prediction/explanation/target cleared and upload generation advances |
| Eight outputs, REVIEW REQUIRED, export control and explanation target | Existing synthetic Streamlit submission tests | Covered with mock model service |
| Scoped server-media/upload clearing | Existing reset-storage test | Covered; downloaded/browser copies cannot be revoked |
| Guided replacement/target/reset and failures | Existing cloud demo tests | Covered; explicit CPU run and safe failure semantics |

Run the new cases with the existing CPU app environment:

```sh
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  python -B -m unittest discover -s tests -p test_demo_robustness.py -v
```

The focused run passed five tests. CI's research-demo Python 3.11/3.12 matrix now
includes them; the broad suite discovers them automatically. In a minimal
environment, image cases explicitly skip without optional Torch/Pillow dependencies;
use the [fresh combined environment](CLEAN_REPRODUCTION.md) for full coverage.

These checks do not establish adversarial security, denial-of-service resistance,
browser-level maximum-upload behavior, simultaneous-user isolation under load,
clinical robustness or accuracy on real retinal images. The declared pixel fixture
checks early size refusal, not a full 25-million-pixel decode. Extreme dimensions
are generated examples, not proof for every codec or malformed file. No new
browser-interaction run or performance benchmark is claimed by this audit.
